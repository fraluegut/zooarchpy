# Roadmap

1. **Phase 1 – MVP (this version):** package, `Specimen`, `Assemblage`, CSV, validation, NISP, percentages, grouping, CSV/JSON export, tests, minimal docs.
2. **Phase 2 – advanced quantification:** MNE (strategy interface, zone-based first), MNI (conservative sided-element), MAU/%MAU with researcher-supplied reference tables. Hand-verifiable examples.
3. **Phase 3 – analysis:** mortality, taphonomy, diversity, biometry.
4. **Phase 4 – research/extensibility:** assemblage comparison, anatomical plots, extensible reference systems, scientific reports.

Also pending: MkDocs site, Excel I/O extra, trusted-publishing release workflow (no PyPI release without an explicit decision).
